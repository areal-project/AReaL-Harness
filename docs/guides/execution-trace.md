# 排查执行轨迹

在会话右侧打开“调用轨迹”，查看当前会话及其委派子代理的已保存执行记录。每轮概览展示排队、执行时间、当前动作、重试与异常，以及较慢的模型和工具调用；点击可定位到详情。

## 理解耗时

排队时间与实际执行时间分开显示。模型请求记录每次尝试的完整耗时、首次内容等待与后续生成，并保留重试失败和等待。工具时间可能包含审批与处理，等待子代理时间与子代理执行可能重叠；这些值不能直接相加得到整轮耗时。

子代理入口按委派关系组织，展开可查看其内部轮次、模型和工具。共享、嵌套以及隔离 worker 的记录都通过 Core 读取；跨轮次追加或等待引用同一执行。任务级子代理与只有父会话关系的旧子代理缺少创建轮次时，列在会话的子代理区域；复制整个会话会保留这些子代理。

运行中的动作显示已持续时间和最后记录时间。状态无法确认、结果未知和耗时未记录分别表达；Core 恢复后缺少结束时间的记录不会一直计时到现在。

## 搜索、筛选与原始结果

搜索包含当前会话与子代理的正文、摘要及调用元信息，也包含折叠和尚未加载的早期历史。结果保留所属会话、轮次及动作，点击后展开定位。搜索仍在读取或部分来源不可用时，面板会说明覆盖情况。

“发生过异常”包含重试后最终成功的记录；“最终失败”单独筛选。耗时筛选默认 10 秒，可选 30 秒、60 秒或自定义，也可以按耗时降序排列。进行中的动作使用已经过时间。

大工具结果可能已经缩略。展开对应结果并选择“查看原始结果”，可在已保存原文中单独搜索；原文缺失或读取失败会显示原因。常规会话搜索覆盖已保存正文与摘要，原始结果附件按需读取。

## 复制与保存

可复制本轮含子代理的轨迹、整个会话的轨迹，或当前筛选结果。JSON 包含时间、状态、错误、模型元信息和关联身份；部分读取的副本明确保留覆盖说明。

日常排查记录随 Core 会话历史保存，与可选轨迹采集上传开关独立。旧记录缺少的新字段显示“未记录”。轨迹详情展示已记录内容与调用元信息，完整模型请求报文仍属于独立诊断材料。

持久状态格式写入版本为 16，继续读取版本 1–15 的记录。回退旧 Core 应恢复升级前备份，参见[本地服务兼容性](../api/local-service.md)。
