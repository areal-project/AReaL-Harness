# 图表规范

架构图说明职责、依赖与所有权；流程图说明执行与控制。每张图标明已实现或设计提案，不加入未经测量的性能数字。

| 项目 | 规范 |
|---|---|
| 格式 | 同名 `.drawio` 源文件与 `.svg` 预览；已有 `.png` 同步更新 |
| 画布 | 默认 1600 × 1000，64 px 边距，8 px 网格 |
| 流向 | 主路径从左到右，最多 6 个主节点、2 层嵌套；超出时拆图 |
| 间距 | 节点横向 64–80 px，纵向 40–56 px |
| 颜色 | 白底；主色 `#0F1012`、正文 `#3A3D44`、次要 `#8B8F97`、边线 `#A0A1A3`、分隔 `#E9E9EA` |
| 字体 | 标题 Baskerville/Georgia；正文 Inter/Helvetica Neue；中文 PingFang SC/Noto Sans CJK SC；协议 SF Mono/Menlo |
| 字号 | 标题 32–36 px，节点 15–16 px，关系 11–12 px；不压缩文字硬塞 |
| 连线 | 正交、避免交叉，箭头指向依赖/数据接收方；执行和控制关系明确区分 |

使用中性灰阶，不添加渐变、阴影、装饰图标或大面积区域底色。布局优先于装饰；相关节点分组，标签简短且不遮挡连线。共享预览保留协议和模块原名，文档正文提供两种语言说明。

文件位于 `docs/design/diagrams/`，正文同时链接预览与源文件。修改源文件后重新导出并目视检查文字、边距、裁剪和线条；不提交生成脚本或无关演示素材。示例见[架构图](architecture.md)。
