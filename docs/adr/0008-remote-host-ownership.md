# 0008：Remote 复用现有桌面后台与 Core 所有权

> 所有权叙述已被 [ADR 0016](0016-shared-host.md) 取代。下文保留早期决策背景；GUI 退出后存活是目标设计，须以共享 Host 验收为准。

桌面已存在独立于 GUI 窗口的后台适配器，以及按项目托管的 Core/Runtime 服务。Remote Gateway 由该后台承载，Core 继续拥有会话与执行事实；不新增 Agent daemon、不让浏览器或 Relay 保存另一份权威 Session。

选择这一边界是为了复用服务发现、凭据保管、提交恢复和工具宿主，避免两个进程争夺同一任务。代价是 P0 仍依赖桌面适配器运行，无法承诺登录前/系统关机后的可用性。

本决策保留 ADR 0001 的桌面模块归属，只改变其早期迁移阶段“不增加 GUI 完全退出后的移动控制”范围限制：实现本功能后，正常 GUI 退出仍保留后台 Remote；系统退出和显式停服不在承诺内。
