# 五题 Harness 历史比较

这是冻结版本的描述性报告，不是当前源码排名。证据见[23 次尝试 JSON](perf-pro-five-evidence.json)。原始镜像为私有来源，完整模型轨迹未随报告公开；该 JSON 可复核聚合，不构成完整公开复现包。

JSON 为脱敏公开副本：模型服务地址、部署标识、私有镜像仓库及错误日志中的地址/请求标识共 10 个字段已替换为明确占位符；占位符不可用于连接或拉取，模型的具体身份未公开。`publication.redacted_fields` 列出字段路径与原因，`original_document_sha256` 标识原始文件，`preserved_payload_sha256` 校验除这些字段外的完整载荷。全部测量值、尝试顺序、失败分类、镜像 digest 和来源摘要保持原值；这两个摘要不冒充当前公开文件的字节摘要。

六个候选题经三方正确答案筛选保留五题，存在事后选择偏差。被淘汰题、失败与补跑仍计入全部 23 次尝试，不能用五题通过推断完整 pro 成功率。
