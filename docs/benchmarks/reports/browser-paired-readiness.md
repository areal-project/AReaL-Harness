导航修复提交为 `19834532`。本地普通链接在准备阶段绑定精确 href、派发前重新校验，再复用已有导航意图。普通按钮保持原行为，变更目的地址在输入前拒绝，脚本导航和接管仍撤权。原生探针的 service 是同步内存 fixture，只证明原生分支；真实 Core 回归单独覆盖工具终态。尚无修复后的真实模型收益对照。

## 独立真实 HTML 验收

第一次尝试因网络传输失败，六次转发均未得到 HTTP 响应，原记录保留。网络恢复后，以独立新身份执行第二次单次验收；模型从不存在的文件开始，自行创建并打开。Core 写入回执摘要与磁盘一致，之后 openDocument 与原生标题、Results、公开 nonce 和单独原生截图一致，正常终态、退出、清理和源码校验通过。

第二次转发八次，其中 Solve 六次。六次有 usage，两次辅助请求取消；已知下界为 input 33,987、output 433 tokens，其中 cached input 11,008 已包含在 input。完整用量与实际 tier 覆盖未知，不据下界推断节省或费用。这次通过只证明该链路，不进入配对样本，也不证明自主生成的泛化能力。

## 配对实验中断与后续

历史 guide-ablation-01 保留 25 条回执、105 条 planned。观察到的普通结果为 14/23 通过，停止为 2/2；这是两组混合的未完成样本，不能当作当前产品分数。共观察到 379 次转发。第 25 项任务未完成目标，Electron 清理在 20 秒超时，子进程非零退出；Core 已停止、在途请求为零、源码一致。事后没有关联进程不改变原清理未知回执，原批次不续跑、不拼接样本。

无模型原生对照复现了展开 SELECT 时内容销毁不结算。固定页面中，DOM 原生 blur 能关闭菜单并正常销毁，没有窗口焦点事件；单纯 MainRenderer focus 未修复真实重放。保持挂载仍失败，重挂不是必要原因。实际资源重放明确等待原生内容并在十秒后失败；不能把它描述为已复现 dispose 漏等。

原生关闭修复提交为 `c19cd5d5`，39 项关闭边界测试通过。最终版本通过未导航空白页、同 ID 重建、展开 SELECT、慢资源及严格第 25 项重放；重放仍任务失败，但 Electron 自然退出、Core 停止，源码前后摘要一致。慢资源场景及时销毁，但该次内部 blur 返回 false，不能据此声称执行了 blur。普通输入、渲染进程崩溃、可控异步屏障及实际 WebM 录制回归属于前一候选版本；最终版仅增加无已提交文档时跳过 DOM 的条件。实际录制在退出前已完成。原失败归档保留，十秒原生等待和二十秒测试退出门槛不变。

[新输入计划](../browser-local-link-plan.json)完整预登记 130 次，比较共享关闭修复的当前产品与单一本地链接修复；实际工件与 freeze 已通过独立准入。旧失败和消费单独保留。目标仍为普通 57/60、停止 5/5、按来源等权且带失败惩罚的 Solve 成本改善至少 15%。

原始证据保存在 `.scratch/browser-hillclimb-v2/`。安装包、跨平台及来源隔离确认尚未验收。
