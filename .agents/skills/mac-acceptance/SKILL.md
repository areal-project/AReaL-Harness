# 交 Mac 验收

## 什么必须交 Mac

只有云端证明不了的才交：签名与公证安装包、钥匙串、自动更新、真实数据升级、手机配对与推送、系统权限（辅助功能、录屏）、截图、深链接、系统通知，以及 `shell-capabilities.cjs` 里其它 `shell` 项。完整清单见 `docs/development/agent-environment.md` 的“Mac 验收清单”。

业务旅程（打开项目、发送、审批、排队、刷新、设置）在网页上验证，不交 Mac 重复点。

## 写清单

每一项写：

1. **前提**：用哪个版本或安装包，是否需要真实数据副本（复制进隔离目录，不直接用 `~/.areal`）。
2. **步骤**：可直接粘贴运行的命令或点击路径。能写成脚本的写成脚本，让用户自行执行。
3. **预期**：看到什么算通过，失败时收集哪些日志。
4. **云端已证明**：哪些部分已在云端通过，附命令，避免用户重复验证。

清单放项目文件，交给用户时一句话说明要做几项、预计多久。

## 收回结果

用户反馈后：通过的项记进汇报；失败的先用 `make baseline-diff` 或同样步骤在基准版本上确认是不是本次改动造成，再修。
