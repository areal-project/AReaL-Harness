## 一、 中式反宇屋面、翼角起翘与歇山两折闭合的数学原理

### 1. 视觉现象 -> 曲面方程拆解
在立面图与鸟瞰图中观察传统坡屋顶，存在三个关键视觉几何特征：
1. **举折反宇凹曲线（上陡下缓）**：屋面剖面不是直线，而是从正脊陡峭下落、到檐口平缓外展的下凹抛物线。设水平进深归一化进度 $\tau \in [0, 1]$（$\tau=0$ 在外檐，$\tau=1$ 在正脊），高度方程为：
   $$z_{\text{slope}}(\tau) = z_{\text{eave}} + \text{rise}\cdot(0.18\tau + 0.82\tau^2)$$
   在檐口处斜率仅 $0.18\,\text{rise}$，在正脊处斜率达 $1.82\,\text{rise}$，自然形成优美内凹弧度。
2. **翼角局部飞翘（中段平直、唯四角翘起）**：正立面看檐口中段完全水平，仅在左右两端翼角向斜上方翘起 $\text{lift}$。设沿檐口参数 $u \in [0, 1]$，径向进度 $r \in [0, 1]$，叠加十次幂角部升起项：
   $$\Delta z_{\text{lift}}(u, r) = \text{lift}\cdot |2u - 1|^{10}\cdot (1 - r)^3$$
   由于在屋檐中段 $u \in [0.2, 0.8]$ 时 $|2u - 1|^{10} < 0.006 \approx 0$，檐口中部保持绝对水平；仅当 $u \to 0$ 或 $1$ 时函数迅速升至 $1$，精准产生四角起翘！
3. **四种屋顶形制的统一内口退化与歇山分段连续**：
   设外檐半宽半深 $(h_x, h_y)$，内收敛半宽半深 $(i_x, i_y)$：
   - **歇山顶（`collar_only=False, i_x > 0.006, i_y > 0.006`）**：侧视图可见屋顶分上下两折，中间夹竖直三角形山花板。取折肩点 $\tau_s = 1 - i_y / h_y$，下段四坡裙边走 $\tau \in [0, \tau_s]$ 停在山花底边 $\pm i_y$；上段前后两坡瓦面从 $\pm i_y$ 沿同一条抛物线走 $\tau \in [\tau_s, 1]$ 严密合拢至 $y = c_y$ 正脊，并在 $x = \pm i_x$ 处挤出贴合弧线坡顶的曲边三角形山花板与悬挑博风脊。
   - **庑殿顶（`i_x = 0.6*h_x, i_y = 0.002`）**：$i_y \to 0$，前后两长坡与左右两三角端坡直接交汇成水平正脊线。
   - **四角攒尖顶（`i_x = 0.002, i_y = 0.002`）**：内外两维同时退化为中心一点，四坡汇聚于宝顶。
   - **重檐下层空心腰檐（显式传 `collar_only=True`）**：仅生成下段四面裙边环，内口 $[-i_x, i_x]\times[-i_y, i_y]$ 保持敞开供上层墙柱穿过。

## 二、 古典凹槽柱卷杀（Entasis）与极坐标星形调制原理

- **视觉特征**：希腊多立克/科林斯石柱并非死板直筒，柱身自下而上微收且中段略呈饱满微凸弧线，表面环绕 $N_f$ 道竖向圆弧凹槽（多立克 20 槽锋利交棱，科林斯 24 槽），在侧光下形成密集竖向明暗韵律。
- **内部数学公式**：设归一化高度 $t = (z - z_0)/(z_1 - z_0) \in [0, 1]$，周向角 $\theta \in [0, 2\pi)$，局部槽内相位 $\phi = \frac{\theta \bmod (2\pi/N_f)}{2\pi/N_f} \in [0, 1]$：
  $$R_{\text{entasis}}(t) = (1-t)R_{\text{bot}} + t R_{\text{top}} + e\cdot R_{\text{bot}}\sin(\pi t), \qquad r(\theta, t) = R_{\text{entasis}}(t)\cdot\bigl(1 - d_f\sin(\pi\phi)\bigr)$$
  正弦项 $\sin(\pi t)$ 赋予柱腰饱满张力；$\sin(\pi\phi)$ 在 $\phi=0.5$ 处刻出圆润凹槽，在 $\phi=0, 1$ 处形成折角 $>32^\circ$ 的锋利亮棱（Arris），配合折痕平滑（`apply_crease_auto_smooth`）自动实现槽内柔滑、槽棱锐利的灰模光影。

## 三、 椭圆平面等弧长参数化（为什么不能直接等分角度？）

- **视觉特征**：椭圆形剧场（长半轴 $a$，短半轴 $b$）外立面的每一跨拱门宽度在视觉上完全均等，且环形墙体处处厚度一致。
- **内部数学原理**：标准参数椭圆 $(a\cos t, b\sin t)$ 的线速度 $\frac{ds}{dt} = \sqrt{a^2\sin^2 t + b^2\cos^2 t}$ 随角度剧烈变化——若直接等分 $t$，长轴端拱门会被压窄 $b/a$ 倍！
  `EllipticalFrame` 内部对弧微分做高密数值积分 $S(t) = \int_0^t \sqrt{a^2\sin^2\tau + b^2\cos^2\tau}\,d\tau$，对任意等弧长坐标 $u \in [0, 1]$ 用二分法反解 $t = S^{-1}(u L)$，并沿精确单位外法向 $\mathbf{n}(t) = \frac{(b\cos t, a\sin t)}{\sqrt{b^2\cos^2 t + a^2\sin^2 t}}$ 向内偏移深度 $d$：
  $$P(u, d, z) = \bigl(a\cos t - d\,n_x(t),\; b\sin t - d\,n_y(t),\; z\bigr)$$

## 四、 多流派穹顶旋转母线与螺旋扭纹肋（Generatrix & Helical Twist）

- **视觉特征与母线方程对应**（高度参数 $t \in [0, 1]$）：
  1. **古典半球穹顶**：$r(t) = R\cos(\frac{\pi}{2}t),\; z(t) = z_0 + H\sin(\frac{\pi}{2}t)$；
  2. **哥特/文艺复兴尖穹顶**：$r(t) = R(1 - t^{1.45})$，顶部以有限斜率交汇成尖顶；
  3. **波斯微膨球根穹顶（Bulbous）**：$r(t) = R\bigl(1 + 0.16\sin(1.45\pi t)\bigr)\cos^{0.78}(\frac{\pi}{2}t)$，腰部鼓出略大于鼓座半径；
  4. **俄式洋葱头 + 螺旋扭纹肋（Onion + Twist）**：膨出项增至 $1 + 0.28\sin(1.35\pi t)$ 配合 $(1-t)^{0.68}$ 反曲尖收，同时每层水平环叠加上升扭转相位 $\theta_i(t) = \frac{2\pi i}{N} + \omega_{\text{twist}} t$，连接同索引节点即得贴合曲面的三维麻花状凸肋。

## 五、 单叶双曲面直纹扭转斜交网壳（Ruled Hyperboloid Diagrid）

- **视觉悖论与数学解释**：摩天观光塔外观呈现明显的细腰内凹曲线轮廓，但全部主柱均为**纯直线段**！
  取底环椭圆节点 $B_i(\theta_i)$ 与顶环旋转扭角 $\Phi$（如 $-125^\circ$）后的节点 $T_i(\theta_i + \Phi)$，做三维线性插值 $P_i(v) = (1-v)B_i + v T_i$。由于上下端存在方位角差 $\Phi$，直线弦在中段更靠近中心轴（半径 $r(v) = \sqrt{x_i(v)^2 + y_i(v)^2}$ 在腰部自然达到极小值），整圈直线柱列包络出精确的单叶双曲面，再连接层间节点即构成斜交网格（Diagrid）。

## 六、 多边形线脚的角平分线斜接补偿（Miter Scale）与局部立面标架（LocalFrame）

1. **拐角斜接公式（消除线脚转角缩水或穿模）**：
   二维截面 $(o_k, z_k)$ 沿平面多边形扫掠腰线/挑檐时，在顶点 $V_i$ 处取相邻两边单位外法向 $\mathbf{n}_{i-1}, \mathbf{n}_i$ 的单位角平分线 $\mathbf{b}_i$，并乘以投影余弦倒数补偿：
   $$\mathbf{m}_i = \frac{\mathbf{b}_i}{\mathbf{b}_i \cdot \mathbf{n}_i}, \qquad P_{i,k} = (V_{i,x} + o_k m_{i,x},\; V_{i,y} + o_k m_{i,y},\; z_k)$$
   保证任意折角两侧的垂直出挑宽度恒等于 $o_k$。
2. **局部立面正交标架与镜像法向保护（`LocalFrame`）**：
   给定任一立面的世界中心 $O$ 与朝外法向 $\mathbf{n}_{\text{out}} = (n_x, n_y, 0)$，定义局部坐标 $(u, d, z)$：$+u$ 沿立面向右、$+d = -\mathbf{n}_{\text{out}}$ 向墙体内部凹入（故 $d>0$ 为窗洞深槽阴影，$d<0$ 为凸出壁柱/檐口）、$+z$ 竖直向上。当矩阵行列式 $\det(M) < 0$（左右镜像对称复制）时自动翻转四边形顶点环绕序，确保所有对称构件外法向 100% 正确。

## 七、 两种开洞拓扑策略的选择准则

- **收分斜墙上的穿堂拱形隧道（`arch_cut`）**：当墙体下宽上窄（`frustum`）且门洞贯穿前后立面时，用闭合拱形棱柱经外法向校准后执行 `EXACT` 布尔减法，真实切出斜墙与圆拱柱面的三维相贯线。
- **平直或弧形立面上的密集门窗阵列（`build_perforated_wall` / `build_curved_arcade_wall`）**：收集所有洞口边界 $\{u_a\} \times \{z_b\}$ 将立面划分为矩形网格，跳过开孔格并补齐弧形拱肩（半圆 $\sqrt{1-u_t^2}$、哥特尖拱 $\sqrt{1-|u_t|(0.62+0.38|u_t|)}$、波斯四心拱 $(1-|u_t|^{1.65})^{0.68}$）与内凹窗套（Reveal），零布尔开销即可生成高密度双流形拱廊。
