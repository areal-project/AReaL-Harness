# Security reporting

The project is under development; see [support boundaries](docs/features.en.md). The Runtime sandbox does not cover Core, explicitly trusted plugin Hosts or remote services.

Report permission bypasses, credential exposure, sandbox escapes or untrusted-input execution through private reporting on the repository's [GitHub Security page](https://github.com/areal-project/AReaL-Harness/security). If unavailable, open an [issue](https://github.com/areal-project/AReaL-Harness/issues) only to request a private contact channel; omit exploit steps, sensitive logs and credentials.

Include commit, operating system, minimal reproduction, expected boundary and actual impact. Use temporary directories and synthetic data; remove tokens, user prompts, private code and internal addresses. Use the issue template for ordinary bugs.

There is no stable-version maintenance window or response-time commitment yet. Fixes require permission, cancellation, persistence and cleanup validation on affected platforms.
