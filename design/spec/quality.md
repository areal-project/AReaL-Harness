# 什么是好的

每个模块交付前对照这里。能自动查的都写了对应检查，其余靠两种主题的标准截图人工看。规格和演练建立在这些标准之上，标准变了先改这里。

## 所有模块

| 标准                                                                                         | 怎么查                                             |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 尺寸、间距、圆角、字号只用变量，不写裸数值；零散值对齐到最近的刻度                           | `design-system-audit`、`layers-lint`（原料层引用） |
| 颜色只用用途变量：悬停、选中、分隔线不手调前景色的透明度                                     | `layers-lint` 的 tint 规则                         |
| 选中和当前项的底色取选中类变量，选中永远不比悬停淡                                           | `layers-lint` 的 selected 规则                     |
| 动效时长、曲线、循环只用动效变量；开启“减少动效”后全部归零                                   | `motion-lint`                                      |
| 悬停不改变布局：隐藏的操作靠叠放出现，不靠挤开别的内容 <!-- rule:R-QUALITY-001 -->           | `popup-anchor-lint`                                |
| 页面不改组件外观，只决定组件放在哪、多大；需要新外观就加组件变体 <!-- rule:R-QUALITY-002 --> | `layers-lint` 的 restyle 规则、`restyle-lint`      |
| 浅色和深色都有标准截图，同一状态两种主题都过                                                 | `conformance/references.mjs`                       |
| 同一个东西只用一个名字：定时任务、工作树、侧边聊天 <!-- rule:R-QUALITY-003 -->               | `terms-lint`                                       |
| 没有多余的空线：空列表不留只剩边框的空卡片                                                   | `display-lint` 的 empty-box 规则                   |
| 一组并排的按钮不折行；放不下就改布局                                                         | `display-lint` 的 wrapped-buttons 规则             |
| 文字对比度不低于下限，标准主题和极端主题都满足                                               | 主题测试、可访问性闸门                             |
| 界面文案不出现英文占位、内部名词或开发术语                                                   | 标准截图人工看                                     |

## 页面框架

- <!-- rule:R-QUALITY-004 -->一个面只有一个标题、一个关闭入口。标签页已经写了名字的面板，内容区不再重复标题。
- 页面说明紧跟在标题下面，和标题算一组；不放进第一个分区之前的空隙里。
- 同一类页面同宽：设置各页都用阅读宽度，不单独收窄。
- 底色只有一层：内容区（包括代码区）不铺第二种底色，不满一屏时不露出另一种颜色。

## 模块

| 模块                                 | 好的样子                                                       | 标准截图                         |
| ------------------------------------ | -------------------------------------------------------------- | -------------------------------- |
| 输入框                               | 空、草稿、运行中、排队各状态高度稳定，操作按钮位置不跳         | `home.*`、`thread.*`             |
| 对话回合 <!-- rule:R-QUALITY-005 --> | 过程默认收起，最终回答直接可读；运行与停止状态一眼可分         | `thread.*`                       |
| 审批与提问                           | 卡片出现在输入框位置，选项可用键盘完成                         | thread.approval、thread.question |
| 侧栏与导航                           | 当前项、运行中、待处理、未读四种标记互不混淆                   | window.sidebar 等                |
| 浮层                                 | 菜单对齐触发按钮，打开期间触发按钮显示为按下                   | `window.*-menu`                  |
| 设置页                               | 行的说明在左、控件在右；控件最多占半行，按钮不折行             | `window.settings-*`              |
| 右侧面板                             | 标签平分宽度，入口列表和快捷键在打开前可见                     | `window.panel*`                  |
| 审查面板                             | 窄栏下文件名不被挤掉，隐藏操作叠放出现；未改动行有中文说明     | `window.review*`                 |
| 文件面板                             | 树里当前文件选中；改动标记与审查一致；深色下代码区与面板同底色 | `window.files*`                  |
| 侧边聊天                             | 空状态说明这是什么，输入框就在底部                             | window.side-chat                 |
| 定时任务                             | 工具栏和列表标题与会话标题栏、侧栏对齐                         | `window.tasks*`                  |
| 插件中心                             | 主区与对话区同底色，侧栏样式同设置导航                         | window.plugins                   |

## 还没覆盖

- <!-- rule:R-QUALITY-006 -->浏览器标签（含标注）和终端标签需要一个假的浏览器、终端宿主才能在规格入口里打开，暂未接入。
- 侧边聊天的内容区还有一行自己的标题和关闭按钮，和标签页重复。
- 模型设置页的次要按钮有的带描边、有的是灰底。
