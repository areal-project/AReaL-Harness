# 基础表达角色

本页维护 AReaL Harness 选择颜色、文字、空间和反馈的用途。数值在哪里改、写样式时用哪个变量，见 [Token 来源与使用](tokens.md)。

## 颜色与内容层级

主文字承载当前任务与可操作内容。次文字承载补充说明和元信息，仍需可读。禁用表示当前不可操作，不能为了降低说明文字的强调而借用禁用角色。

页面、内容、输入、浮层和边界用各自角色表达关系。一个分组表达一个功能关系，不给每段文字增加独立卡片、重阴影或装饰渐变。选中表示当前选择，强调表示操作优先级，危险表示操作后果。成功、警告、错误与待确认分别传达事实，不能仅凭颜色辨认。

## 文字与空间密度

标题帮助定位，正文承载阅读，控件标签说明动作或值，说明文字补充范围。路径、代码和标识使用便于逐字核对的表达。UI 字号与内容字号分别承担操作和阅读职责，不能合并为一个偏好。

默认排印采用用户指定的 Codex 参考图右侧（“字体 2”）方向：常规字重、清晰且克制的无衬线文字。任务列表与普通正文不默认加粗，选中态用已有表面反馈表达，字重强调留给标题和确需强调的内容。截图只支持左侧笔画更厚、字面略大的视觉比较，不能单独证明字体家族、精确字号或缩放比例。

当前实现使用系统 UI 字体，macOS 由系统西文字体与苹方简体中文混排，其他平台采用所属系统的无衬线回退；具体字体栈、常规字重和字号仍由生产 Token 与外观设置维护。该选择以参考的阅读观感为目标，不宣称已识别或复刻 Codex 的专有字体。默认字号沿用现有刻度，尊重用户字体与阅读字号选择。

界面文字的字号只用 `--text-ui-*` 角色，这样用户调整界面字号时所有界面文字一起缩放；写死的像素字号会让该处不随偏好变化。没有合适角色时先在 tokens.json 增加角色，而不是写新的像素值。

同行控件采用一致密度，同组内容用间距说明关系。空间不足时重排，必要信息不靠缩字或裁切隐藏。控件形状与容器形状各有用途：圆角从 `--radius-*` 按表面选择，不逐页追加任意尺寸或圆角。

## 图标、动效与焦点

图标帮助识别已有对象和操作，资产沿用[设计基础](README.md#图标与资产)。图形大小、布局占位与命中范围分别核对，纯图标保留可访问名称。

动效解释状态变化和空间连续性。等待动画不证明执行仍在推进，停止动画也不证明后台已经结束。明确动效的起止状态与可中断方式。减少动态效果时保留同样的信息与动作。

控件保留所属平台的标签与键盘语义。键盘焦点说明当前输入和操作位置。焦点、选中与悬停分别表达。打开、关闭、导航和对象切换后的焦点由宿主负责，异步更新不抢走当前输入。

GUI 的既有轮廓规则与本地 Web 的原生控件共用 [focus.css](../tokens/focus.css) 中的焦点宽度与偏移。两处保留焦点颜色与组件选择器，按钮已有的 ring 表达不改成轮廓。该共享范围不包含焦点导航控制器或用户偏好。

GUI 的具体接线见[基础规则](../../clients/gui/design-system/foundations.md)。后续 Web 复用这些角色时按浏览器能力适配，并独立核对焦点与可访问性。
