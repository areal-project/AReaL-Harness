# D-002 共享语义先于统一数值与实现

已采用共享浏览器焦点默认值。其余角色先按 GUI 收敛，Web 接入时核对复用范围。

2026-10-24 的 [D-004](004-local-ui-package.md)进一步采用本地 UI 包，首批既有 GUI 值迁入单源 Token 并生成产物；以下保留最初焦点共享的背景与未迁入范围。不是新增一份并行的可编辑默认值。

GUI 确立设计角色及默认值，不以多个客户端同时采用为前提。Web 后续复用这些角色时，核对现有主题源、浏览器能力与偏好边界，避免直接复制形成第二套可编辑定义。[Token 地图](../foundations/tokens.md)维护实际来源和已接入范围。复核条件是 Web 的真实需求无法沿用 GUI 角色，或共享默认值需要共同版本和漂移检查。

首组将焦点宽度与偏移的既有默认值迁入 [focus.css](../tokens/focus.css)。GUI 直接导入，Core 编译时与本地 Web 样式拼接。两个消费者均使用 CSS，因此不增加 JSON 或生成器。颜色、选择器、批准控制器与动态偏好保留原所有者。扩大范围前另行核对真实消费者和平台能力。
