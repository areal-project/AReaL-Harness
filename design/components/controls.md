# 按意图选择控件

先判断用户改变的是值、位置、可见信息还是执行状态，再选择控件。控件外观不能改变动作语义。具体组件、尺寸和有限变体由 GUI 实现合同决定。

| 用户意图 | 交互含义 | 选择约束 |
| --- | --- | --- |
| 执行一次操作 | 发出一个动作或打开入口 | 使用操作控件，不伪装成持续状态开关 |
| 开启或关闭持续状态 | 同一个状态可双向改变并读取实际值 | 后端必须支持两个方向；单向停止、清理等仍是操作 |
| 从候选中选一个值 | 一个明确值取代另一个值 | 保留当前值和选中语义，不与步骤或导航混用 |
| 选择多个值 | 多个候选可以同时成立 | 保留复选语义，不套用单选 API |
| 切换位置或视图 | 改变当前阅读上下文 | 与设置值选择分开，保留返回及未提交内容 |
| 查看更多信息 | 改变展示范围 | 使用明确的展开、收起或详情入口，不改变保存与执行状态 |

同一流程的先后步骤不是互斥选项。不能为了对称外观给单向维护操作添加虚假的开启入口。操作中、已选、禁用和键盘焦点分别表达，不用视觉选中冒充已保存。

GUI 的两项与多项设置选择、按钮变体和展开形式继续见[控件映射](../../clients/gui/DESIGN_SYSTEM.md#按交互类型选择控件)。后续 Web 复用时保留控件语义，并核对浏览器中的键盘、焦点与可访问性。
