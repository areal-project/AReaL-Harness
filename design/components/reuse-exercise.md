# 独立复用题：交付物核对

本题用于检验冻结的有限 Base 能否支持一项新任务。它是开发预览中的本地模拟任务，不进入生产路由，不连接 Core、文件系统或模型服务，也不代表真实交付物已经核对。

## 固定任务

用户核对一次任务留下的交付物，需要筛选类型、查看选中对象、执行一次核对，并区分成功、明确失败与结果未知。核对结果始终属于对象 ID，不能因筛选、刷新资料或窗口改变而移动到另一对象。

初始筛选为全部，选中 `guide`。所有对象初始未核对。资料刷新次数为零。页面显示当前使用的 Base 版本和本地模拟边界。

| ID | 名称 | 类型 | 资料 | 核对的固定结果 |
| --- | --- | --- | --- | --- |
| guide | 项目快速开始.md | 文档 | 当前可用 | 已核对，内容与记录一致 |
| trace | 本轮执行过程与工具返回记录-包含中文和English的长文件名.ndjson | 记录 | 当前可用 | 明确失败，文件已移走 |
| screenshot | 结果截图.png | 图片 | 当前可用 | 已核对，内容与记录一致 |
| remote | 远端模型产物.bin | 其他 | 仅远端可用 | 本地核对不可用，解释原因 |
| draft | 交付摘要草稿.md | 文档 | 资料可能过期 | 结果未知，保留操作标识，用户显式核对结果后确认为已核对 |
| metrics | 运行指标.json | 记录 | 当前可用 | 已核对，内容与记录一致 |

## 必须能完成的操作

- 筛选支持全部、文档、记录、图片、其他和视频。视频没有对象，显示可理解的空状态。
- 列表显示名称、类型与当前结果。选择对象后能读到完整名称、资料状态和核对结果。
- 点击“核对交付物”后显示处理中，禁用重复触发，保留对象身份。一次操作只结算一次。
- 核对正在处理的对象时仍可筛选或选择其他对象。迟到结果只更新原对象。
- 明确失败在对应对象旁说明原因。返回该对象仍能看到失败结果。
- 结果未知时不能自动重复核对。提供“核对结果”，仅由用户显式触发结算。
- “刷新资料”只刷新资料次数和资料说明，不重新发起核对，不清空已知结果，也不改变仍在列表内的选中对象。
- 筛选排除当前对象时，选择筛选后的首个对象。筛选结果为空时不保留一个不可见的详情对象。切回全部时显示全部对象，已有结果保留。
- 仅远端对象的核对动作不可用，原因在界面中可见。
- 键盘可到达筛选、对象选择、刷新与核对动作。可见焦点与文字不因切换主题或宽度而消失。

本地模拟操作约在半秒后返回固定结果。时间用于展示处理中状态，不承担业务语义。离开页面时取消本页尚未完成的模拟任务。

## 可访问语义与反馈

筛选名称为“类型筛选”。对象选择按钮的可访问名称包含完整文件名。详情区域名为“交付物详情”，其标题显示选中对象完整名称。动作使用“刷新资料”“核对交付物”和“核对结果”。资料刷新次数显示为“资料刷新：N”。

核对状态使用“未核对”“处理中”“已核对”“明确失败”和“结果未知”。未知结果显示“操作标识：”及非空标识。语义与文案在实现前固定，评估不要求特定页面布局。

## 固定实现输入

实现输入为某个已提交、状态为 frozen-beta 的 Base 快照。版本、冻结提交与检查结果由该题的运行记录提供，不能随工作树继续变化而替换。

消费入口为生成的 `base-components.ts`。允许使用 React、冻结入口中的成员、普通语义 HTML、已有 `SettingsPage` 与组合承担的布局，以及现有生产文字工具类。组件接口以冻结类型为准。

不增加组件，不写页面专用 CSS，不加入内联视觉数值，不更改 Token，不读取参考页面实现或截图。需要额外样式或接口时，先记录无法表达的需求，作为后续归因材料。题目容器可由既有开发预览提供宽度、滚动与主题条件。

题目的实现者只接收本题、冻结 Base 文档、消费入口及其类型。评估材料独立保留。已有探索题和同会话看过的产品候选不能当作本题的独立结果。

## 代表条件

明亮主题、14 字号、宽容器；深色主题、18 字号、窄容器；减少动态效果；键盘操作；长名称；处理中切换对象；明确失败；结果未知后的显式核对；空筛选结果。检查内容完整、对象归属、操作可达和复用方式，视觉评价与行为检查分别记录。
