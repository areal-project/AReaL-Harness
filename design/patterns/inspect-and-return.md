# 深入查看与返回

`R-RETURN-001` 先判断用户要快速核对、持续阅读还是编辑，再选择有界预览、显式展开或独立阅读区域。信息层级不能靠缩小字号、无提示裁切或嵌套滚动代替。

## 长内容与全文

展开后用户能继续阅读，收起后能找到原操作及上下文。正文之外的附件和动作保持可达。同一内容的人工选择按[过程阅读](task-progress.md)处理。
