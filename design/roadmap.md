# 设计系统建设顺序与缺口

AReaL 已有生产控件、GUI 目录、状态合同和开发预览。[完整工作台候选](products/workbench/candidate.md)把设计选择组合成可操作的任务路径，供整体评价。五条切片已有真实 GUI 自动化证据：任务、外观、文件与 Diff、[插件资源管理](patterns/plugin-resources.md)和[阅读恢复](patterns/feedback-and-recovery.md)。第四条覆盖查找与筛选、详情、当前项目启停、失败与 UNKNOWN 原回执核对、返回原列表及原任务；第五条覆盖同窗口 Renderer 刷新及崩溃后显式重载，恢复已加载阅读段落与草稿，原执行继续且不重复提交；前四条已在同一生产实现上回归。

2026 年 10 月 23 日，用户对前两条切片的首轮反馈为“目前看没什么问题，和现在的基准版本差不多”，当前保留基准视觉方向。文件与 Diff、插件、阅读恢复切片仍待用户体验评价；自动化证据不表示用户已认可整体视觉或全部状态。

## 当前进展

[Base beta](../clients/gui/design-system/base.md)的 0.2 冻结输入已完成[交付物核对独立题](components/reuse-result.md)，复用已有组件和 Token，无页面 CSS。0.4.0 在插件资源有限路径上增加同窗口 Renderer 阅读恢复，共 20 个成员、3 个模式；既有独立题在精确冻结输入上的迁移回归已通过，不作为新的盲试。成员、合同、兼容边界与运行证据仍由 Base 及其证据索引维护。

## 当前基础与缺口

| 能力 | 当前基础 | 仍需完成 |
| --- | --- | --- |
| 产品设计语言 | [共享原则](principles/README.md)、[表达角色](foundations/roles.md)、[完整工作台候选](products/workbench/candidate.md)沿既有角色形成整体 | 用户评价文字层级、表面、密度、形状、状态和动效，并收敛下一轮选择 |
| 内容与文案 | [术语](content/terminology.md)、[界面文案](content/interface-copy.md)已区分用词建议与执行事实 | 随真实入口采用并核对翻译、范围和反馈，不做脱离功能的全局替换 |
| Token | [角色与平台映射](foundations/tokens.md)、[浏览器焦点共享源](tokens/focus.css)已接入；首组焦点有 GUI 与本地 Web 键盘审批证据，任务切片已统一主要动作颜色、阅读宽度、间距和过程附注字号 | 默认调色板与状态色已由 tokens.json 单源生成并有重定义守卫；存量字号/颜色/圆角字面量由[基线](foundations/tokens.md#自动守卫)只减不增，继续按页面收敛到零；Web 后续按实际接入独立验证 |
| 组件合同 | [组件选择与职责](components/README.md)连接首批就近合同、生产消费者引用与类型导出检查；[分层与成熟度](components/README.md#成熟度)由审计按生产使用自动核对 | 后续成员按真实需求准入，Props 仍由类型提供 |
| 用户任务与组合 | [共享模式](patterns/README.md)、[完整候选](products/workbench/candidate.md)串联任务、过程、审批、资源与设置；五条切片均有真实 GUI 自动化证据 | 后三条切片待用户评价；完整资源管理、插件安装/认证/连接和其他异常恢复按真实需求单独验收 |
| 文档与可运行示例 | [文档与预览入口](README.md#阅读与预览)、现有 catalog 与生成器 | 核对原 Markdown 链接、合同和生产示例的阅读路径；运行结果另行记录，不以构建代替用户路径 |
| 变更约束与准入 | [目录检查](../clients/gui/scripts/design-system-catalog.mjs)、[增量审计](../clients/gui/scripts/design-system-changes.mjs)约束有限成员；Base 0.2 已完成独立复用，0.4.0 按列明插件与阅读恢复范围有限冻结 | 同题复验沿迁移回归入口记录，不追加新盲试结论；Web 接入时另行验证 |

当前文案是采用建议，工作台包含设计要求、源码映射与本地可操作候选，就近合同也不等于生产行为验收。文档入口和已有示例形成首条阅读路径，首条任务切片已沿真实 Electron、Core 和 Runtime 验证，模型事件由本地确定性服务提供。其他路径、真实供应商和安装包仍需分别验证。GUI 的 [Base beta](../clients/gui/design-system/base.md)当前按 0.4.0 有限冻结；P-RESOURCES 仅准入列明的插件目录、详情、当前项目启停与回执返回，完整插件安装/认证/连接、P-CONVERSATION、SidePane、列明同窗口 Renderer 恢复以外的生命周期与跨平台仍未完成。现有目录主要检查引用与声明，不能证明实际 JSX 采用了对应组件，也不能代替视觉或平台验收。

## 下一步

先评价五条切片的整体体验，继续覆盖文字层级、表面、密度、形状、状态与动效；文件与 Diff、插件资源及阅读恢复三条新增路径需单独记录用户反馈。0.4.0 的既有独立题复验沿原入口保留迁移回归边界，不替代真实 GUI 或用户评价。

后续以用户评价、实际任务出现的缺口及异常恢复为方向，回到原组件、模式和业务所有者修订。没有真实需求时不继续扩大目录、成员或基础设施。GUI 优先；真实供应商、安装包、Web 和其他平台在实际接入时另行验收。

验证证据的职责边界统一见[架构](architecture.md#验证边界)。以下条件是持续目标，已完成范围以 Base 与运行证据为准。

## 首轮完成条件

- 同一候选覆盖工作区、对话、资源、设置及所选异常路径，整体视觉决定可审查。
- 所选 Token 和组件有明确所有者、真实消费者、状态合同与验证位置。
- 文档中的示例使用生产实现，目录生成与漂移检查通过。
- 行为、视觉、原生平台与安装包分别报告实际覆盖，未覆盖项保留。
- 原有调用方完成迁移，被替代定义删除，新增任务能复用同一设计选择。

本目录只维护中文。平台现有文档与外部用户文档继续遵循各自的维护约定，不在本轮批量删除既有译文。
