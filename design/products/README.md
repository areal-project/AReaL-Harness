# 产品与工作台

产品文档把共同设计选择放到完整使用路径中。它说明信息放在哪里、用户怎样进入与返回，以及哪些事实仍由原控制器提供。

当前条目是[桌面工作台](../../clients/gui/design-system/workbench.md)。它连接项目、聊天、定时任务、资源和设置。GUI 模式及后续 Web 复用依据归[交互模式](../patterns/README.md)，组件选择归[组件目录](../components/README.md)。

`R-ENTRY-044` 先完成桌面 GUI 的设计与生产迁移。后续 Web 复用时独立核对导航、输入、阅读与平台能力，桌面路径或开发预览通过不能证明本地 Web 和 Remote Web 已完成相同路径。
