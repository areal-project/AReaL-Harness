# 界面文案

本页给出 AReaL Harness 的文案建议和评审依据，不声明所有客户端已采用这些措辞。执行事实、审批范围和恢复保证分别以[控制与审批](../people-and-agents/control-and-approval.md)及原服务契约为准。

## 操作名称说明点击后的动作

当前值留在字段或选中状态中。切换控件不写一次性动作。纯图标操作提供同义的可访问名称，提示文字补充必要范围，不承担唯一名称。

## 反馈先说已知事实

`R-COPY-002` 错误提示只有一个来源：后台给错误码，用户看到的句子登记在[错误文案表](../../clients/gui/renderer/src/errors/errorCopy.ts)，每条说发生了什么、工作是否受影响、现在能做什么，并带一个动作。界面不直接显示错误对象的原文；原文和错误码只进“查看详情”。不出现 Host、Core、受理、核对、回执等内部说法。**检查：** `clients/gui/scripts/ui-honesty-lint.mjs`

`R-COPY-005` 项目、对话、任务对用户只呈现[用户可见状态](../../clients/gui/renderer/src/state/userStates.ts)里的几种状态。新的内部状态先决定落到哪一种用户状态，不在视图里另加分支或直接读连接、Run 字段。**检查：** `clients/gui/renderer/src/state/userStates.ts`

| 事实 | 建议表达 | 使用条件 |
| --- | --- | --- |
| 正在读取 | 正在读取… | 表达读取，不暗示任务重新启动 |
| `R-COPY-003` 尚无记录 | 尚未运行 | 已确认列表为空，不能用于首次加载或读取失败 |
| 已收到，尚未开始 | 已发出，等待开始 | 已确认收到，不写“运行中” |
| 已完成 | 已完成 | 所属对象已确认完成。保存成功、轮次完成和任务完成各有范围 |
| 已确认失败 | 没有完成。可查看原因。 | 有失败事实，下一步只提供当前合法动作 |
| `R-COPY-007` 已知内容的刷新失败 | 更新失败，显示上次读取的内容。 | 已有可保留内容，不能把旧值说成当前值 |
| `R-COPY-008` 结果未知 | 还不确定是否完成。请先查看结果，内容已保留。 | 没有确定结果，不能写成成功、失败或未执行 |
| 没有权限 | 这台设备没有权限做这个操作。 | 已确认权限原因，避免将所有连接问题归为权限不足 |
