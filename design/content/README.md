| 命名动作，表达等待、审批和未知结果 | [界面文案](interface-copy.md) |
| Markdown渲染采用开源能力还是自有组件 | [开源复用调研与建议](markdown-reuse-review.md) |
| 核对Codex字体及截图的证据边界 | [字体核对](codex-typography-review.md) |
| 正文、公式、图表和交互页面怎样共同呈现 | [对话内容呈现系统](conversation-content-system.md)（[官方资料调研](interactive-content-research.md)、[外部建议复核](native-content-reference-review.md)） |

对象的职责与授权含义由[人与 Agent](../people-and-agents/README.md)维护。反馈位置与恢复动作由[反馈与恢复](../patterns/feedback-and-recovery.md)维护。GUI 及实际接入的 Web 文案键、翻译与展示归原实现，不在本目录复制字符串清单。
