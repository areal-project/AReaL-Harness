## 何时使用

| 场景 | 选择 |
| --- | --- |
| 提交、打开或执行一次动作 | Button |
| 按需展开阅读 | [Disclosure](../disclosure/disclosure.md) |
| `R-BUTTON-001` 持续状态/取值选择 | 原 Switch / Select，不用按钮模拟 |
