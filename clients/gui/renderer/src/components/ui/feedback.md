# Feedback 反馈

## 用途

操作错误通过同一顶部Toast通知，状态正文仍在所属组件附近展示。保留用户正在查看的对象和输入。

## 不适用

反馈文字不承担动作入口，不替代审批、恢复和结果核对。需要用户决定时使用所属流程的交互控件。

## 状态

有 `error` 时经ToastHost显示error等级提示，默认5秒后消失；不在页面上留下错误卡片或折叠详情，有id时保留屏幕阅读器关联说明。否则有 `message` 时显示原位置的 `status` 正文，两者均为空时不渲染。Props 与实现以 [feedback.tsx](./feedback.tsx) 为准。明确失败与结果待核对使用不同事实描述。

## 键盘与焦点

Toast不主动移动焦点，关闭按钮可通过Tab到达；悬停或聚焦暂停计时。调用方保留原操作位置，必要动作使用独立且有名称的按钮。

## 禁用

反馈没有禁用状态。所属动作不可用时，说明原因；提示消失后，原任务/表单仍保留当前输入和必要恢复信息。
