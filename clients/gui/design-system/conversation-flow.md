# 对话流设计系统：活动与上下文

状态：2026-10-24 设计目录与生产对话共用组件，仍保留实验导出与有限Base边界。生产接线见文末，设计预览继续供状态评审；不把采用等同于完整模式准入。适用桌面GUI的主聊天、活动详情与任务上下文；Side等复用Messages的入口共享活动呈现，Remote及各入口宿主仍分别验收。

用户目标是把两张 Codex 截图中反复出现的结构变成可复用的设计语言：正文负责沟通，活动行负责说明做了什么，展开区负责核对细节，右侧负责整理当前工作的对象与输入。视觉沿用现有 AReaL Token、图标和控件，不从截图另建主题。

## 可操作预览

从仓库根运行 `pnpm --dir clients/gui design:dev`，打开 [对话流设计预览](../renderer/design-system.html?conversation-system)。建设看板和组件目录也提供“对话流设计”入口。

预览提供运行中、已完成、需要关注三种状态，来源数量可选零、三、五项，图片可切换可用/引用不可用。活动与图片默认收起；三十项列表、追加命令输出、文件/变更入口、子任务、来源折叠/查看全部、添加示例网页到草稿和窄窗上下文返回均可操作。切换状态保留同一组的人工展开和未发送草稿，刷新则回到初始样例。

任务上下文卡片默认关闭，从对话顶部“任务上下文”按钮打开，不是永久的右侧面板。过程摘要可切换模型文字、长摘要与无摘要回退，通过“推进摘要样例”验证变化；这些是显式固定样例，不模拟真实模型流或按时间编造进度。

## 研究后的优化选择

再调研资料及事实/推断边界见[参考记录](references.md#2026-10-24-过程摘要上下文卡片与组件文档再调研)。这版是基于反馈与研究的候选改进，不代表完整或最佳Codex复刻。

| 问题 | 优化决定 | 可观察结果 |
| --- | --- | --- |
| Thinking被误当成唯一过程内容 | 优先呈现公开模型摘要，无摘要才回退；文字更新局部过渡，扫光附着于当前文字 | 切换与推进样例可看到新文字；长摘要换行；等待/未知不冒充正在思考 |
| 上下文卡片与资源面板混为一体 | 顶部开关控制有限高度卡片；子代理历史是独立阅读区 | 初始不占右列，expanded/controls一致，Escape回入口；进入历史暂收卡片，关闭后恢复 |
| 连续更新打断阅读或混淆权限 | 摘要不抢焦点、不定时生成、不推断执行结果；原活动记录独立保留 | 更新不提交/重试，来源/草稿/子任务选择不随文字变化重置 |
| MD存在但像薄说明书、在站点不可见 | 实现旁MD维护完整结构与元数据；站点显示关联、原文与该组件的独立示例 | 每份目录组件可找到同目录MD、用途与状态、类型API和可操作例子，生成检查拒绝缺失结构 |

卡片使用非模态阅读：可以继续主对话，显式按钮/Escape关闭；当前不因普通外部点击自动丢弃阅读状态。窄窗保留顶部开关和返回入口。这个关闭策略、阅读器优先及返回恢复是产品选择，不从静态参考推断。

宿主适配位于 [ConversationSystemPreview](../renderer/src/design-system/ConversationSystemPreview.tsx)，固定数据位于 [conversationSystemScenario](../renderer/src/design-system/conversationSystemScenario.ts)。活动、图片和右侧基本外观已由私有包的实验对话组件提供；本地 CSS 仅保留页面布局与 ToolEvent/SentAttachment 适配。复用原 CommandDetails、ConversationComposer 和 WorkbenchShell。图片来自既有仓库示例，文件/网页/变更/子任务详情是本地说明，不读取真实项目、不执行命令、不连接 Core 或供应商。

| 实验组件 | 就近规范 | 预览实践 |
| --- | --- | --- |
| ActivityGroup | [活动分组合同](../packages/ui/src/conversation/activity-group/activity-group.md) | 30项原 ToolEvent，纵向滚动、增量/完成保留展开、折叠外状态 |
| ImageDisclosure | [图片折叠合同](../packages/ui/src/conversation/image-disclosure/image-disclosure.md) | 默认收起、原图片查看器、引用不可用仍保留反馈 |
| TaskContext | [上下文合同](../packages/ui/src/conversation/task-context/task-context.md) | Section/Item/Sources 组合变更、项目、子任务、来源；宿主返回与草稿保留 |
| SubagentPanel | [子代理面板合同](../packages/ui/src/conversation/subagent-panel/subagent-panel.md) | 入口→分状态全部列表→子任务历史→原列表；过多完成项展开 |
| ThinkingStatus | [思考提示合同](../packages/ui/src/conversation/thinking-status/thinking-status.md) | 左到右扫光、静态减少动效、不可见/后台停止 |

这些组件均从 `@areal/ui/wip` 消费，独立样式为 `@areal/ui/conversation.css`。[UI 包预览](../renderer/design-system.html?ui-library)用普通活动文本、原生图片和本地动作独立消费同一组件，不加载 renderer 工作台样式。API、组件索引、Agent 索引和 Markdown 来自包构建，尚未提升为稳定入口或 Base 准入。

相关检查：`pnpm --dir clients/gui design:build`，然后 `pnpm --dir clients/gui test:design --conversation-system`。专项沿既有浏览器 runner 检查默认折叠、人工选择跨完成保留、纵向滚动、图片加载与查看、来源状态以及窄窗返回，保留截图与 manifest。浏览器结果不代表真实执行、完整应用生命周期、安装包或用户视觉认可；下面的目标合同仍需分别按实际覆盖验收。

## 依据与规则强度

| 依据 | 可以确定什么 | 不足以确定什么 |
| --- | --- | --- |

| 图二及四条标注 | 右侧包含 Changes、当前 Worktree 下关联的其他项目、Subagents、Sources；Sources 可折叠，默认列出三项并可查看全部；来源可以是图片、网页及其他输入 | 关联项目的数据合同、网页摄取与存储机制、来源删除权限 |
| [Raft 本地源码核对](references.md#raft设计知识组件与产品分层) | 通用控件与领域组件分层；模式和产品布局分开；文档、参数、示例各有真实来源 | Raft 的聊天领域、字体和数值不自动成为 AReaL 规范 |
| 当前生产源码 | 已有活动、详情、资源与父子对话的所有者，见下文映射 | 已有组件不代表本草案已经实现或通过验收 |

“用户要求”沿本轮标注执行；“设计默认”是为补齐规范提出的可调整选择。现有 [CONV 合同](patterns.md#对话信息流)继续拥有执行、阅读、分组与返回约束；本草案补充候选形态，不复制一套规则 ID。正常完成时的过程总组收敛与这里的活动组默认收起是两个层级。

## 设计系统如何组织

沿 [AReaL 架构](../../../design/architecture.md)和 [D-004 私有 UI 包](../../../design/decisions/004-local-ui-package.md)组织，复用已有包、Token/主题和目录构建链，不新增平行组件库或页面 DSL。

| 层 | 本题维护什么 | 唯一来源与后续落点 |
| --- | --- | --- |
| Foundations | 内容/控件文字、次级信息、表面、间距、图标、焦点和动效角色 | [GUI 基础规则](foundations.md)、[Token 指南](../DESIGN_SYSTEM.md#token-选择)及生产 CSS/偏好链；本稿不存数值副本 |
| 通用控件 | 按钮、折叠、列表语义、反馈和详情容器 | 包内基础 Button/Disclosure 及原控件；不认识 Thread、processId 或权限结果 |
| 对话领域组合 | 活动组、图片入口与任务上下文 | 首批 src/conversation 实现与就近合同；命令、子代理资源与权威状态沿原所有者，接口以真实类型为准 |
| 交互模式 | 活动何时分组、怎样展开、回看与返回 | [过程阅读](../../../design/patterns/task-progress.md)与原 CONV 合同；不接管 Core 状态机 |
| 产品布局 | 主阅读列、右侧上下文、查看资源及窄窗返回 | [桌面工作台](../../../design/products/workbench/README.md)与现有 App 宿主 |
| 目录与示例 | 找到合同、真实实现及已覆盖状态 | 原 registry、设计文档阅读器与生产组件预览；未实现概念不登记成可用组件 |

上表的实验导出有实际类型和合同；下文其他英文名称仍是设计词汇，不构成新增导出或 Props 承诺。若现有所有者能够承担，直接补齐它的合同与有限变体。

## 主阅读列与活动层级

| 层级 | 内容 | 默认呈现与用途 |
| --- | --- | --- |
| 会话正文 | 用户消息、助手过程说明、最终回答 | 保留独立身份、顺序与完整阅读能力；正文不因附近工具增加而变成命令输出 |
| 过程总组 | 本轮过程文字与常规活动 | 沿 CONV-GROUP-01：正常结算且 final 明确后可收敛；仍运行、待决定、失败与未知保持可发现 |
| 活动组 ActivityGroup | 同一轮、同一段连续工具活动 | 用户要求默认收起；露出类型摘要、数量和必要状态。手动展开后显示有序活动列表 |
| 活动行 ActivityRow | 读取、命令、编辑、图片或子代理的一条事实 | 类型图标 + 动词/对象 + 必要状态 + 明确动作；保持轻量，不把每一行绘成卡片 |
| 活动详情 | 原命令与输出、读取记录、变更、图片或原始回执 | 用户按需展开或打开原资源阅读器；同一对象的不同动作有独立入口 |

这是可用的层级，不要求每条活动都套满五层。单条活动直接使用活动行；不为了做组而额外包一个同名标题。

分组使用原有事件身份与连续顺序：不跨用户消息、助手说明或最终回答合并，不把不同轮次或不同项目的活动混在一起。同一进程的输出读取沿 processId 归并为一条命令记录，不增加“执行次数”。图片和子代理使用各自变体，不因邻近命令而失去类型与入口。

### 活动行的有限变体

| 变体 | 收起时回答什么 | 展开或主要动作 | 内容边界 |
| --- | --- | --- | --- |
| Read / 读取 | 读取了哪个文件；多项可摘要为“读取文件” | 打开文件；独立入口查看该次读取记录 | 文件当前内容与当时读取回执不同，必须保留来源区别 |
| Command / 运行命令 | 执行了哪条命令，当前运行/退出情况 | 展开原命令、工作目录、输出、退出码及收集状态 | 工具返回不等于进程退出；查看与复制不会重跑 |
| Edit / 编辑 | 修改了哪个文件；有可信回执时显示本次增删 | 查看本次差异或文件；原始记录次一级 | “已编辑文件、运行命令”是混合活动摘要，不是编辑已执行命令的操作 |
| Image / 查看图片 | “已查看图片”及数量或可识别名称 | 用户要求图片内容默认关闭；手动展开缩略图后可进入原图片查看器 | 这是工具活动图片的规则。用户输入附件与最终交付图片仍按自身内容合同呈现 |
| Subagent / 子代理 | 可识别的任务名称与独立状态 | 打开该子对话；创建回执可另查 | 创建成功、子任务完成、父任务完成是三种事实；不从模型自述生成完成状态 |
| Mixed / 混合摘要 | 该段实际发生的类型，如“读取文件、编辑文件、运行命令” | 展开原顺序活动 | 沿现有展示投影归类，不解析 shell 文本猜测读写权限，不以一种图标代替全部事实 |

活动名称描述真实动作。运行中使用“正在运行”，完成后使用“已运行”；失败、未知、仍在收集输出分别保留。没有准确计数或耗时就省略，不制造百分比。图标辅助识别，文本承担含义。

### 折叠与状态

| 对象/条件 | 默认 | 人工操作与后续增量 |
| --- | --- | --- |
| 常规活动组与命令详情 | 收起；当前活动与必要状态在摘要可见 | 打开后保持同组选择，追加输出与完成事件不强制关闭 |
| 工具活动图片 | 图片内容收起，保留具名入口 | 选择展开后保留选择；加载失败在该入口附近反馈 |
| 正常完成的过程总组 | 沿原合同收敛，final 独立 | 不覆盖同身份的人工展开；不把父组收起当作清空子项选择 |
| 待审批、失败、UNKNOWN、未结算 | 状态与合法入口在收起摘要外层仍可发现 | 关键决定不能藏在待展开的日志里；用户仍可收起详情，无需强制打开全部输出 |
| 切换项目/会话/轮次 | 读取该对象自身的默认或选择 | 不继承另一对象的展开状态；跨应用重启保存展开值不是本轮要求 |

活动组收起不等于停止执行。展开、复制、查看全部、打开子任务与返回均是阅读动作，不提交、重试或恢复未知写入。

### 溢出与滚动

用户要求活动组只纵向滚动。展开后列表有界增长，超过所属容器的阅读上限才出现纵向滚动；摘要留在滚动列表之外。具体高度随容器与字号验证后由原组件负责，不从截图取一个固定全局值。

- 活动摘要可截断，展开详情必须能读全。长命令、路径、URL 和无空格输出在可用宽度换行；复制保留原始字符与换行。
- 不能仅隐藏横向滚动条而裁掉内容。活动列表及其内嵌命令正文不产生横向滚动，也不撑宽主聊天。
- 长命令/输出按需进入既有详情区域，避免在活动组内再套多层独立纵向滚动。完整 Diff、图片缩放与专用阅读器按原资源合同处理；命令组规则不取消这些阅读器的必要平移。
- 每个区域只有一个滚动所有者。内层到边界后的滚动行为由原宿主核验，不用脚本把主聊天拖回最新；展开与折叠继续保留阅读锚点。

## 右侧任务上下文

顶部按钮打开的任务上下文卡片回答“当前工作涉及什么”。顺序为当前工作归属与 Changes → 关联项目 → Subagents → Sources。它与中间时间线共用对象身份：时间线按发生顺序叙事，卡片按对象整理入口，不能分别维护一份执行事实。

| 区块 | 摘要形态与内容 | 用户动作与范围 |
| --- | --- | --- |
| Changes / 变更 | 当前项目名称、明确的变更范围、文件数及可信增删统计 | 打开原 Diff/变更面板；工作区变更可能包含用户或其他任务修改，不能全部归为本 Agent 产出 |
| Related projects / 关联项目 | 用户要求列出当前 Worktree 下的其他项目；每项显示名称与展开入口 | 设计默认：项目详情先收起，展开后查看其归属与已有资源入口。仅列确有上下文关联的项目；无关系数据时不拿所有最近项目代替 |
| Subagents / 子代理 | 用户要求有列表；设计默认：摘要展示有限头像与按真实状态分类的计数，展开为具名任务列表 | 打开同一个子对话；失败、待决定、未知与运行中状态可见，不能用“11 done”概括混合状态 |
| Sources / 来源 | 可折叠区块、总数、添加入口；展开时最多三项及“查看全部（总数）” | 设计默认：首次打开右侧时展示三项预览；收起只留标题/总数，查看全部进入原宿主中的完整来源列表，返回恢复原位置 |

这里的“关联项目”描述产品上下文关系，不断言多个 Git 仓库物理处于同一个 Git Worktree，也不因展开而切换 cwd 或修改执行范围。关系与标识要在原 Worktree/项目合同明确后绑定；本轮不新增跨项目查询服务。

Subagents 入口首先打开全部列表，按Active/Needs attention/Done区分任务状态，配合头像、状态图标和文字。完成项过多时先展示十项，可展开和收起；Active为零有明确空态。点击某项进入该子代理历史，显示请求、过程、活动与结果；返回保留列表展开、阅读位置与原行焦点，关闭恢复原入口。宽窗将子任务阅读器与主对话并列，暂收上下文卡片；窄窗进入单独阅读区，不替换成一段概括说明。

父任务与子任务状态分别提供。预览增加独立子任务状态切换，涵盖一项运行中/全部完成/一项需要确认，不从父任务结算推导子任务。运行中的历史可显示Working及公开模型过程摘要，无摘要时回退Thinking；已确认完成显示Worked和最终结果，未知显示待确认。用户标注确定当前过程文字亮度从左到右扫过；周期是实现选择。减少动态效果保留静态文字，离屏与后台停止；不在完成态或未知态继续扫光。

任务概览卡片与深入阅读的面板是两个用途。顶部入口在所有宽度可达；阅读子任务时暂收卡片，关闭后恢复。复用 WorkbenchShell / SidePane 的尺寸与导航，不按截图百分比固定侧栏，不叠出第二套常驻侧栏。打开项目或资源不丢失主聊天草稿、阅读位置及来源入口。

各区块分别处理读取状态：首次加载显示读取中；确认空集合后才显示“无变更/无子任务/无来源”；局部读取失败在所属区块反馈，不伪装成零项。刷新时保留已确认内容与人工折叠选择；断开连接或旧数据无法更新时标注可能过期。迟到响应只能更新原项目/会话，不覆盖当前上下文。

### Sources 管理输入

用户要求的 Sources 是输入来源集合，可容纳图片、网页、文件及其他已有引用类型。工具生成的截图、编辑文件和执行回执属于过程证据或产物，不因被展示就自动进入输入列表。Agent 读取过的文件可作为明确标注的“读取记录”入口，但与用户提供的输入分开表达；采用后的分类含义归[上下文与证据](../../../design/people-and-agents/context-and-evidence.md)。

| 条目组成 | 规则 |
| --- | --- |
| 身份与类型 | 使用原 URI、资源 ID 或引用身份；显示图片/网页/文件等类型，不只凭文件后缀判断 |
| 可识别名称 | 文件名、页面标题或可理解的名称为主；路径/域名为辅助。无标题时展示已有定位信息，不补造名称 |
| 归属与状态 | 区分草稿待发送、已随消息提交、显式引用、读取记录；存在于列表不证明进入本次模型请求、被理解或验证 |
| 预览与打开 | 图片可预览，网页交给原浏览器/链接入口，文件交给原文件阅读器；不可读取时保留名称与状态 |
| 三项预览 | 设计默认：按首次加入顺序稳定展示，刷新不跳位；同一资源身份不重复，具有独立版本的引用不静默合并 |
| 查看全部 | 超过三项才出现；完整列表在有界区域纵向滚动，支持返回三项预览；零项显示简短空态与可用添加动作 |
| 添加与移除 | “+”沿原附件/引用能力进入主草稿，发送前可移除；不静默写入正在执行的上下文。已发送历史只读，移除草稿引用、释放上传与删除资源是不同动作 |

支持网页这一设计类型不代表本轮承诺自动抓取、持久化网页全文或新增上传后端。不支持的来源仍可显示原引用并说明可用打开方式。

## 视觉与可访问性

活动采用轻量行式表达，右侧分区使用已有面板表面与分隔；命令正文只在展开后获得内容区域。最终回答保持最高阅读权重，正常结束的过程使用次级表达，但不能把运行/失败内容做成禁用态。

过程摘要消费 `--text-content-caption`，控件标签消费 `--text-ui-caption`，次级信息沿 `--color-foreground-subtle/subtlest`；代码沿 `--font-mono`，阅读列沿 `--reading-width`。间距、圆角、状态颜色和字号偏好只引用 [GUI Token 指南](../DESIGN_SYSTEM.md#token-选择)，不登记截图数值或 Raft 字体副本。

折叠触发器是具名按钮，Enter/Space 可切换并暴露 expanded/controls；文件打开、详情展开、复制与菜单分别是独立目标，不嵌套按钮。“查看全部”带来源区上下文与数量。被收起内容退出焦点序列；收起正在聚焦的内容时将焦点交回触发器。滚动区溢出时可键盘到达和纵向滚动，图片有可理解名称，纯图标动作有可访问名称。颜色与动画均不独自承担状态；沿已有 reduced motion 和可逆折叠机制。

| 样例 | 固定内容/动作 | 应观察到的结果 |
| --- | --- | --- |
| 基础活动 | 两次读取、一次命令、一次编辑、一个图片活动、一个子代理；穿插助手说明 | 类型可辨、原顺序保留；连续活动才成组；图片/常规组默认收起，正文仍可读 |
| 混合长列表 | 三十项活动、超长无空格命令与路径、多批长输出 | 组可纵向滚动；无横向位移和裁字；详情可读全，复制保持原文；进入长详情不形成多层滚动陷阱 |
| 人工展开与结算 | 运行中展开命令及图片，再追加输出、子任务完成、父任务完成 | 人工选择保留，父子状态独立，final 独立；收起父组后再开仍能找到原详情 |

| 来源集合 | 零项、三项、四项；混合图片、网页和文件，含同名异源与不可用项 | 默认最多三项、超出可查看全部、可折叠返回；名称和归属可核对，不把生成图片误算为输入 |
| 窄窗与返回 | 明/暗、内容/UI 大字号、长名称、打开资源后返回；键盘与减少动态效果 | 主阅读与发送可达，无页面横向溢出；草稿、阅读与合理焦点保留，不能靠缩小字体通过 |

## 生产接线

生产主会话、子历史及复用Messages的入口消费同一实验包；不复制预览fixture或另建执行状态。TurnExecution负责原事件分组，单项以inline呈现，增加条目后同实例折叠；活动默认收起，人工选择跨增量和完成保留，失败/UNKNOWN在折叠外。

ToolEvent通过ImageDisclosure按需阅读已确认的工具图片，原SentAttachment负责Core媒体读取和查看器，读取失败在折叠外反馈。用户输入附件与最终交付图片保持原呈现。TurnActivity以连接、审批、重试、工具和未确认状态为先，仅在实际模型生成期间使用ThinkingStatus；消费Core reasoning.summary公开摘要，无摘要回退，不从modelContext提取隐藏信息。

App沿原顶部“任务资源”入口承载TaskContext。Sources来自已保存附件、已验证文件读取及用户明确网页引用；仅展示引用不宣称抓取，三项/全部/返回由原卡片维护。加号打开原Composer附件入口，只加入草稿。关联信息仅来自实际worktree.sourceRoot/directory，不把工作区内任意目录列为关联项目。Changes仍为工作区未暂存范围，定时任务与后台进程保留原动作。

Subagents入口先打开分状态列表，再进入AgentConversationPane真实历史，时间线子任务仍可直达。AgentsPane继续拥有原agents/agentWait分页查询与状态，AgentHistoryPane仅拥有阅读选择；失败、中断、未知使用原状态文字，不由父任务结算推导。原子任务管理页不替换。阅读卡片暂收起，关闭阅读器恢复；卡片通过React Activity保留阅读状态，隐藏期间清理查询effect。SidePane继续负责资源标签与主对话草稿/焦点返回。

实验导出保留wip；生产采用不等于稳定API、完整Codex复刻或Base升级。真实桌面验收与安装包、供应商能力分别记录。
