# 无障碍验收

## 默认主题修订

`R-ACCESSIBILITY-002` Base 0.4.1 提高了最弱元信息、已结算状态和浅色次要文字的可读性。警告橙色按钮使用黑色文字。审批快捷键使用次要文字角色。旧 `theme-baseline.json` 继续作为 Base 0.4.0 快照，只有 `theme-accessibility-revision.json` 列明的四个角色按精确输入和输出更新；其他角色必须与旧快照一致。D3 的颜色等价证据保留，本修订属于 D4 的显式行为改变。

## VoiceOver 抽查

- 发送。输入名称、编辑内容和发送后状态可理解。
- 审批。请求正文、批准与拒绝可定位，结果更新会被正确朗读。
- 停止。当前 Turn 的停止入口可达，停止受理与后台终止能区分。
- 设置。分组标题、控件值、校验信息和返回焦点符合阅读顺序。
