# 变更、证据与验收

## 变更准入

`R-EVIDENCE-002` 新增模式或公共变体，在对应规则文件登记适用任务、默认状态、生产所有者及验收条件。局部例外在变更说明中写明规则 ID、文件/组件、具体原因、证据和退出条件；持续例外在所属规则旁维护。例外必须有范围，不能整文件豁免。图标固有色、语法高亮、图表等先核对已有所有者，不以“特殊设计”为由绕过语义角色。

v1 不对存量页面做批量迁移。发现差异先登记在[覆盖与缺口](inventory.md#覆盖与缺口)中对应范围；只有阻碍当前任务或由本次变更造成的差异才扩展实现范围。

系统级登记、页面合同和生成检查见[自动化机制](automation.md)及[结构化流程](structured-flow.md)。`verify:design` 检查这些声明与派生物，但不静态证明 JSX 符合声明。

## 证据分层

| 证据 | 能证明 | 不能证明 |
| --- | --- | --- |
| 源码、类型与静态审计 | 接口存在、依赖与已扫描范围的 Token 使用 | 用户能完成任务、视觉一致 |
| 生产组件 fixture | 挂载的组件、主题、字号、宽窄和列明状态 | Core、真实供应商、安装包、原生窗口 |
| AReaL 真实桌面 | 该源码/包及该场景的窗口和交互 | 未运行的平台、账号、其它场景 |
| Codex 实例截图 / DOM | 该版本该状态的参考外观与可见结构 | AReaL 已实现、内部尺寸规范、未观测交互 |
| 官方网页中的产品插图 | 指定公开参考图的视觉构图 | 当前本机 Codex 或动态行为 |

`R-EVIDENCE-003` 每组截图记录：run ID、捕获时间、参考/实现模式、应用版本或源码 SHA 与 dirty 状态、进程/目标、场景前提、到达动作、可见完成条件、主题、viewport、DPR、字号/字体、原图路径与 SHA-256、关联规则、观察/推断/偏差/缺口。未知项写 unknown。证据摘要可入规范，带账号、私有路径或对话内容的原图留本地；发布另按授权范围处理。

## 有界问题与逐步证据

`R-EVIDENCE-006` 材料有效性与测试结果分开：完整捕获、部分/裁剪、未请求、不可用分别标明；只有完整可见的材料支持整段视觉结论。超长组合可保留原始部分截图并逐行补采，不能悄悄丢弃失败材料。原图存在或哈希相同不自动证明布局完整、交互相同或设计合格。

## 差异筛选准入

`R-EVIDENCE-014` 比较时先区分默认状态与人工展开、主动回看与自动跟随、父命令与子任务、不同run或重置。图像内容、字号、面板宽度或语言不同时，列出可比较维度；例如不同尺寸图片仍可比较缩放控件是否存在，但不能据此宣称同像素布局。验收依据是预先固定的合同，不能在看过结果后降低要求。

`R-EVIDENCE-015` 核查记录与页面合同各司其职：本地记录保存原图/原始模型答复和逐项裁决，surface声明状态与证据缺口，规范只保存稳定的采纳决定。保留未关闭项和失败运行；本机私有路径、账号、聊天与采集档案不进入公开源码。静态例外与工具不可用分支按默认流程处理，无需为每个小改动创建完整视频包。

## 动态信息流的关联证据

`R-EVIDENCE-016` 动态结论沿用同一个 run manifest，关联事件、阅读位置、录像段及关键帧；不另建一套执行或历史权威。静态终态图不能单独证明自动跟随、完成时收敛、人工展开保留或操作顺序。

| 记录 | 最低必要信息 | 判断边界 |
| --- | --- | --- |
| 可见变化 | 当前回复/工具/分组身份、文字长度或必要增量、运行/完成指示 | 增长只从目标回复读取，排除用户提示、未发送预测建议、计时器和无关区域；可见文字不是后端回执 |
| `R-EVIDENCE-018` 阅读位置 | 滚动容器、scrollTop/clientHeight/scrollHeight、具名内容锚点及相对位置 | 结合用户滚动与后续内容增长判断跟随/回看；尺寸或scrollTop单独变化不能判定阅读被打断 |
| `R-EVIDENCE-019` 细节展开 | 所属轮次、总组/子组/单条详情身份、展开值、默认或人工来源 | 父组收起与子项丢失状态分别判断；新建总组不能冒充同一个旧展开状态 |
| `R-EVIDENCE-020` 媒体关联 | 录像段身份、起止时间区间、关键帧事件 ID、原图哈希与实际条件 | 同一时钟或明确的时钟映射；不能校准时标明偏移未知或误差区间 |

`R-EVIDENCE-021` 只保存回答当前问题所需的可见内容及只读观测，不采账号或凭据，不读取参考应用私有状态来补造执行事实。终态条件绑定当前助手输出和独立运行/完成指示，不能因用户提示中出现末标记就判为回复已完成。

## Agent-browser 采集约定

`R-EVIDENCE-025` 独立实例由任务授权启动；是否关闭遵从用户当次要求。认证由用户完成，不读取或导出 cookies、token、账号存储；不以连接成功代替登录和目标可用。页面截图不能覆盖 native menu 或 WebContentsView 的独立验收。

## 按改动选择检查

- 公共视觉组件/Token：执行[Base 复验入口](base.md#复验入口)，按受影响的明暗、字号与宽窄状态保存对应证据。
- `R-EVIDENCE-027` 业务交互：追加该路径的既有验收；涉及 IME、权限、未知提交、原生窗口时使用相应真实桌面场景。类型检查或 fixture 不能替代。

完整迁移清单审计与[增量设计检查](automation.md#增量设计检查)同时运行：后者自动发现生产 renderer 的新增/修改 CSS、TSX、JSX。评审继续核对复制组件、遗漏状态和语义偏离；静态检查不覆盖动态间接样式或视觉判断。
